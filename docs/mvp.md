# SmogCast MVP

## MVP Goal

The goal of the SmogCast MVP is to provide users with a simple next-day forecast of PM10 and PM2.5 concentrations for selected monitoring stations in Poland, based on historical air quality data and weather conditions.

## User Stories

1. As a resident, I want to check the next-day PM10 and PM2.5 forecast for a selected station so that I can better plan outdoor activities.

2. As a resident, I want to see the predicted pollution level in a clear and easy-to-understand form so that I can quickly assess air quality.

3. As a user, I want to select one of the available monitoring stations so that I can receive a forecast for the location I am interested in.

4. As a user, I want to see the latest available PM measurements together with the next-day forecast so that I can compare the current situation with the predicted one.

5. As a user, I want to view recent historical measurements so that I can understand how air quality has changed over time.

6. As a user, I want to see information about data freshness and quality so that I can better interpret the forecast.

## MVP Scope

### Included

- next-day PM10 and PM2.5 forecasts
- selection of supported monitoring stations
- latest PM10 and PM2.5 measurements
- historical measurement charts
- station map
- air quality assessment based on GIOŚ thresholds
- use of historical GIOŚ data
- use of Open-Meteo weather data
- predictive model based on historical data
- data freshness and coverage information
- backend API
- Streamlit dashboard
- support for selected stations with sufficient data coverage

### Intentionally Out of Scope

- user accounts and authentication
- user profile personalization
- push, email or SMS notifications
- forecasts for all GIOŚ stations in Poland
- automatic user location detection
- forecasting pollutants other than PM10 and PM2.5
- multi-day forecasting
- mobile application
- advanced health alerts
- medical recommendations
- integration with private sensors or IoT devices
